# linyu-news-feed

林语的「行业见闻」数据源：一个每天自动运行的小爬虫，把文博/文物修复行业的公开新闻整理成一个 `news.json`，供 Tavo 插件「行业见闻」读取，让角色在聊天时自然知道行业里今天发生了什么。

## 它每天做什么

北京时间 07:00（GitHub Actions 定时任务）：

1. 检索 Google News 的四个关键词（南京博物院 / 文物修复 / 考古发掘 / 文物保护），并尝试直抓国家文物局、中国文物新闻网
2. 过滤：丑闻、负面、旅游攻略类硬排除；标题必须命中文博专业词
3. 打分挑选，每天最多 2 条（涉及考古调动的「事件级」最多 1 条）；同一事件的多源报道只留一条
4. 与 `crawler/seen.json` 比对去重，出现过的新闻永不再选
5. 结果写入 `news.json`，同时在 `digest.md` 里存一份人类可读的日报存档

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `news.json` | 插件读取的当日 feed（机器读） |
| `digest.md` | 日报存档（人读，年底整理世界书时可当素材库） |
| `crawler/crawl.py` | 爬虫脚本（纯 Python 标准库）。想调整口味就改文件开头的配置区：检索词、排除词、打分词都在那里 |
| `crawler/seen.json` | 去重记录，一般不用管 |
| `.github/workflows/daily.yml` | 定时任务定义 |

## 插件那边填什么

Tavo 插件「行业见闻」的设置里，把「新闻 feed 地址」填成这个仓库的 raw 地址：

```
https://raw.githubusercontent.com/<你的用户名>/linyu-news/main/news.json
```

## 说明

- 本仓库只处理公开新闻数据，不含任何个人信息，可以放心设为公开仓库（公开仓库的 Actions 免费额度更宽裕）。
- 某天没有符合条件的新新闻时，`news.json` 的 items 会是空数组，这是正常的——宁缺毋滥。
- GitHub 的定时任务偶尔会延迟几分钟到几十分钟，不影响使用（插件读到的仍是当天日期的文件才会注入）。
