# linyu-news

林语的「行业见闻」数据源：一个每天自动运行的小爬虫，把文博/文物修复行业的公开新闻（外加一小组 jiaying 自己生活圈的话题）整理成一个 `news.json`，供 Tavo 插件「行业见闻」读取，让角色在聊天时自然知道今天发生了什么。

## 它每天做什么

北京时间 07:00（GitHub Actions 定时任务）：

1. 按 `topics.txt` 里的搜索词检索 Google News，并尝试直抓国家文物局、中国文物新闻网
2. 过滤：旅游攻略类硬排除；他的行业一组标题必须命中文博专业词；负面/丑闻新闻单独把关（只收国内大媒体报道的大新闻）
3. 打分挑选，每天最多 3 条（「事件级」最多 1 条，负面大新闻最多 1 条，「她的近况」最多 1 条）；同一事件的多源报道只留一条，同一负面题材 7 天内不重复
4. 与 `crawler/seen.json` 比对去重，出现过的新闻永不再选
5. 结果写入 `news.json`，同时在 `digest.md` 里存一份人类可读的日报存档

## 想换话题？改 topics.txt 就行

搜索词都在仓库根目录的 `topics.txt` 里，分 `[他的行业]` 和 `[她的近况]` 两组。手机 Safari 打开该文件 → 点铅笔图标 → 一行一个词，加行或删行 → 拉到底点 Commit changes 保存，第二天生效。不需要改代码。评分、排除等细则在 `crawler/crawl.py` 开头的配置区。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `topics.txt` | 搜索词清单（jiaying 自己维护的话题入口） |
| `news.json` | 插件读取的当日 feed（机器读） |
| `digest.md` | 日报存档（人读，年底整理世界书时可当素材库） |
| `crawler/crawl.py` | 爬虫脚本（纯 Python 标准库） |
| `crawler/seen.json` | 去重记录，一般不用管 |
| `.github/workflows/daily.yml` | 定时任务定义 |

## 插件那边填什么

插件「行业见闻」v1.0.1 起已内置本仓库的 feed 地址，装好即用，无需填写：

```
https://raw.githubusercontent.com/xinran1213/linyu/main/news.json
```

## 说明

- 本仓库只处理公开新闻数据，不含任何个人信息，可以放心设为公开仓库（公开仓库的 Actions 免费额度更宽裕）。
- 某天没有符合条件的新新闻时，`news.json` 的 items 会是空数组，这是正常的——宁缺毋滥。
- GitHub 的定时任务偶尔会延迟几分钟到几十分钟，不影响使用（插件读到的仍是当天日期的文件才会注入）。
